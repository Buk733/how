# how

Браузерные игры для [Яндекс Игр](https://yandex.ru/games/).

Цель — игры, которые цепляют с первых секунд и надолго удерживают игрока: проверенная механика, трендовая обёртка и своя внутриигровая экономика (монеты, награды за рекламу, кейсы, колесо удачи, апгрейдер).

## Основы игр

Каждая основа — отдельная игра. Делаем по очереди:

| # | Основа | Суть | Статус |
|---|--------|------|--------|
| 1 | **Собери / укради X** | Ловишь или крадёшь персонажей, ставишь на базу, они приносят доход. Кейсы, колесо удачи и апгрейдер — источники редких персонажей. | В работе: «Укради Брейнрота: Баня», готовы покупка, доход, кражи у соседей, веник, прокачка, музыка, кейсы, колесо удачи, парилка-апгрейдер, «Голда» (v0.4), а также большой мир с лесом, огородом, прудом и пасхалками и соседи, которые прокачиваются вместе с игроком (v0.5), плавные тропинки, объёмные машины и порталы (v0.5.1); в v0.6 уже есть выбор героя и мягкая музыка — [дизайн](docs/game-1-steal.md) |
| 2 | **Мерж + пассивный доход** | Сливаешь одинаковых персонажей в более редких, они приносят монеты. | Позже |
| 3 | **Обби-паркур + коллекция** | Полосы препятствий в 3D, за прохождение — монеты и кейсы со скинами. | Позже |
| 4 | **Кейс-симулятор / кликер** | Тапаешь, копишь монеты, открываешь кейсы. | Позже |

Исследование рынка и правил площадки (сентябрь 2026): [docs/research-2026-09.md](docs/research-2026-09.md).

## Запуск

Нужен [Node.js](https://nodejs.org/) 22.12 или новее.

```bash
npm install
npm run dev        # игра на http://localhost:5173
```

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает игру с автообновлением при правках |
| `npm test` | юнит-тесты (Vitest) |
| `npm run build` | проверка типов и сборка в `games/steal/dist` — эту папку заливаем на Яндекс Игры |
| `npm run preview` | открывает собранную версию |
| `npm run art` | перерисовывает спрайты и текстуры из `tools/art` |

## Управление

- **Компьютер:**
  - WASD или стрелки — бегать;
  - E или пробел — действие (купить, украсть, открыть место, закрыть щеколду, потрогать пасхалку);
  - F или левая кнопка мыши — шлёпнуть веником (соседа или его собаку);
  - U — прокачка, K — кейсы, L — колесо удачи, P — парилка, H — выбор героя, Esc — закрыть окно;
  - колесо мыши — приблизить или отдалить.
- **Телефон:** проведите пальцем по экрану — появится джойстик. Справа внизу кнопки действия и веника, слева — кнопки окон.
- Справа вверху: 🔊 выключает весь звук, 🎵 — только музыку, портрет героя — выбор героя (аниме-девушка или качок).

## Структура

```
engine/            общий движок для всех игр: спрайты, камера, ввод, звук, подписи
  batch.ts         тысячи неподвижных спрайтов одной отрисовкой (лес, цветы)
  boxes.ts         объёмные модели из коробок с пиксельными картинками на гранях
  ground-marks.ts  тропинки, грядки, песок, дорога — пиксельная картинка на земле
  chiptune.ts      синтезатор мелодий: ноты текстом → звук, без файлов
  pathfinding.ts   поиск пути в обход стен
  platform/        Yandex Games SDK и локальная заглушка (сохранения, реклама, пауза)
games/steal/       игра №1 «Укради Брейнрота: Баня»
  src/data/        персонажи, герои, редкости, кейсы, пасхалки, фразы
  src/economy.ts   правила экономики (покупка, замена, доход, «Голда», цены мест)
  src/upgrades.ts  прокачка: цены уровней и что они дают
  src/cases.ts     кейсы: шансы, что выпало, чем платить
  src/wheel.ts     колесо удачи: призы, шансы, таймеры
  src/upgrader.ts  парилка: во что можно превратить персонажа и с каким шансом
  src/neighbors.ts правила соседей: их персонажи, цель вора
  src/rivals.ts    прокачка соседей: уровни, закалка, собака, колокольчик
  src/secrets.ts   пасхалки: какие найдены и сколько дают
  src/layout.ts    карта: двор, тропинки, поляна, огород, пруд, дорога, порталы, где пасхалки
  src/save.ts      формат сохранения и его проверка
  src/music.ts     фоновая мелодия «Банная полька» и балалайка медведя (ноты)
  src/world.ts     бани, дорожка, трубы, фонари, будки
  src/portals.ts   порталы на концах дорожки: площадка, ворота, воронка
  src/scenery.ts   лес, следы на земле, огород, пруд, поляна, дорога, птицы, бабочки, утки
  src/vehicles.ts  объёмные машины: «копейка», трактор и легковушка на дороге
  src/landmarks.ts пасхалки: избушка, медведь, колодец, рыбак, «копейка»…
  src/carpet.ts    дорожка: персонажи на продажу
  src/home.ts      баня игрока: полок, плиты, щеколда, пар и болтовня на полке
  src/neighborhood.ts  соседи-боты: охрана, погоня, щеколды, набеги, месть
  src/guard-dog.ts собака соседа: лает, кусает, прячется в будку
  src/broom.ts     веник игрока
  src/effects.ts   блёстки, пыль, пар, монеты в кошелёк, тряска камеры
  src/menus.ts     окна: прокачка, кейсы, колесо, парилка
  src/ui/          интерфейс: монеты, кнопки, окна
  src/game.ts      игровой цикл
  src/assets/      спрайты и текстуры (генерируются `npm run art`)
  src/sounds/      мемные звуки персонажей
tools/art/         пиксель-арт, нарисованный кодом
docs/              дизайн игр и исследования
```
