# CLAUDE.md

Контекст для Claude Code в этом репозитории.

## Проект

- Серия браузерных игр для Яндекс Игр. Список основ и статусы — в `README.md`. Исследование рынка и правил площадки — `docs/research-2026-09.md`: сверяйся с ним, прежде чем проектировать механику и экономику.
- Пользователь пишет по-русски — отвечай по-русски. Тематику и референсы (внешний вид) задаёт пользователь. Механику, экономику и удержание предлагаешь ты, опираясь на проверенные жанры.
- Текущая игра — №1 «Укради Брейнрота: Баня» (`games/steal`). Дизайн, состав персонажей и этапы — `docs/game-1-steal.md`.
  - Готовы v0.1 (основной цикл), v0.2 (кражи, соседи-боты, погоня, набеги, щеколда), v0.3 (веник, охрана и щеколды соседей, прокачка, музыка, новые персонажи), v0.4 (кейсы, колесо удачи, парилка-апгрейдер, «Голда»), v0.5 (детали: лес, огород, пруд, поляна, пасхалки, прокачка соседей, собаки, отклик) и v0.5.1 (плавные тропинки, объёмные машины, порталы с воротами). v0.6 готова, кроме доводки первой минуты (по отзывам): выбор героя (аниме-девушка или качок), мягкие голоса музыки, доход вне игры, награды за вход, альбом коллекции и перерождение. v0.7 (экономика) готова, кроме проверки темпа на живых игроках: модель прохождения и тест темпа, новые цены персонажей, мест и кейсов, правило силы соседей, доход вне игры и цена перерождения. v0.8 (Яндекс SDK) готова в коде: облачные сохранения с локальной копией, магазин за Яны, рейтинг, вход, GameplayAPI на переходах. v0.9 (подготовка к выпуску) готова: 7 языков, печь-каменка с мягким паром и дымом, тёплый солнечный свет, потолок дохода вне игры — 20% монет, архив для Консоли (`npm run package`). Дальше — v1.0: Консоль, черновик и модерация по шагам из `docs/yandex-release.md`.
  - Порядок дальше задал пользователь: сначала детали (по отзывам), потом экономика, Yandex SDK — в конце. План — v0.6 удержание, v0.7 экономика, v0.8 SDK.

## Разработка

- Стек: TypeScript + Vite + Three.js, тесты — Vitest. Мир в 3D, персонажи — пиксельные спрайты-билборды.
- Команды:
  - `npm run dev` — запуск игры;
  - `npm test` — тесты;
  - `npm run build` — проверка типов и сборка;
  - `npm run art` — перегенерировать картинки;
  - `npm run pacing` — таблица темпа по модели прохождения;
  - `npm run artifact` — демо-сборка для артефакта (игра по ссылке);
  - `npm run package` — сборка и архив для Консоли Яндекс Игр (`games/steal/release/steal.zip`) с проверкой правил площадки.
- Перед коммитом: `npm test && npm run build`.
- `engine/` — общий движок для всех игр, импортируется как `@engine/...`. Код конкретной игры в него не тащить.
- Чистая логика — в отдельных модулях с тестами рядом (`*.test.ts`): `economy.ts`, `upgrades.ts`, `cases.ts`, `wheel.ts`, `upgrader.ts`, `neighbors.ts`, `rivals.ts` (прокачка соседей), `secrets.ts` (пасхалки), `offline.ts` (доход вне игры), `daily.ts` (награды за вход), `collection.ts` (альбом), `rebirth.ts` (перерождение), `shop.ts` (покупки за Яны), `records.ts` (когда отправлять рекорд), `pacing.ts` (модель прохождения), `layout.ts` (карта), `save.ts`, `spawner.ts`, модули `engine/` (в том числе поиск пути `pathfinding.ts`, пачки спрайтов `batch.ts`, цветокоррекция `light.ts`, следы на земле `ground-marks.ts`, модели из коробок `boxes.ts`). Графику и DOM держать в `game.ts`, `world.ts`, `stove.ts`, `campfire.ts`, `puffs.ts`, `scenery.ts`, `landmarks.ts`, `vehicles.ts`, `portals.ts`, `carpet.ts`, `home.ts`, `neighborhood.ts`, `guard-dog.ts`, `broom.ts`, `effects.ts`, `menus.ts`, `retention-menus.ts`, `shop-menus.ts`, `entities/`, `ui/`. Общие сервисы для них — `GameContext` (`context.ts`), его реализует `Game`.
- **Мир:** где что стоит — `layout.ts` (двор, поляна, огород, пруд, пасхалки, невидимые стены чащи, тропинки `TRAILS`, дорога `ROAD`, порталы и путь персонажей по дорожке `walkPoint`). Бани — `world.ts` (конёк с дранкой и наличником, мелочи на стене), печь-каменка с трубой, огнём и отсветом — `stove.ts` (одна модель на все бани), лес и декор — `scenery.ts`, пасхалки — `landmarks.ts` (живой костёр медведя — `campfire.ts`), машины — `vehicles.ts`, порталы — `portals.ts`.
- **Свет** — `engine/light.ts`, числа — `LIGHT` в `config.ts`. Мир без освещения (объём «запечён» в картинки), настроение задают:
  - цветокоррекция каждого пикселя (`applyColorGrade` через `CustomToneMapping`: тёплый баланс, зелень к жёлтому, насыщенность, контраст, оттенки теней и светов). Её проходят все материалы, кроме `toneMapped: false`; свой `ShaderMaterial` подключает `#include <tonemapping_fragment>` перед `<colorspace_fragment>` (как пачки в `engine/batch.ts`). Небо и туман Three.js подмешивает после неё — их цвет пропускать через `gradeColor`;
  - затемнение углов `createVignette` — один прозрачный слой поверх сцены;
  - отзывы владельца: холодная блёклая картинка — плохо, не возвращать; засвет солнца и лучи поверх кадра выглядели «как спрайт» — убраны, не делать; тепло потом сбавлено на 10% («слишком желтовато») — не разогревать;
  - картинки в `tools/art` рисовать в прежней палитре: тепло добавляет коррекция, иначе цвета «перегреются».
- **Пар и дым** — мягкие полупрозрачные клубы `puffs.ts` (`PuffPool` — пул, `PuffSource` — постоянный источник): проявляются, растут, поднимаются и тают. Картинка клуба белая (`sprites/puff.png`), цвет и прозрачность задаёт `PuffLook`. Пиксельные клубы с резкой сменой кадров для пара и дыма не делать — выглядят дёшево (отзыв владельца). Неподвижный декор добавлять через `add()` в общую пачку листа (`engine/batch.ts`, одна отрисовка на лист), анимированный — отдельными `BillboardSprite`. Высокие спрайты не ставить сразу к югу от мест, где ходит игрок: билборды наклонены назад и закроют их.
- **Глубина спрайтов:** билборд повёрнут к камере, а в буфер глубины пишет глубину стоячей вертикальной фигуры (`uprightDepthGlsl` в `engine/sprite.ts`, его используют `BillboardSprite`, `createStaticSprite` и пачки). Поэтому персонаж у скамейки, печи или стены не «уходит в текстуру», а за стеной по-прежнему прячется — при любом повороте камеры. Свои `SpriteMaterial` (клубы пара) этого не делают: для персонажей и декора брать готовые.
- **Земля:** тропинки, грядки, песок, колея и дорога — не полосы-текстуры, а следы (`engine/ground-marks.ts`): при запуске рисуются в пиксельную картинку, у тропинок плавные изгибы и скруглённые или сходящие на нет концы. Новую тропинку — точками в `TRAILS`; следы одного стиля подряд сливаются без шва на развилках.
- **Объёмные модели** (машины, ворота порталов) собираются из коробок (`engine/boxes.ts`) с картинками на гранях из `tools/art/vehicles.mjs`, материал без освещения с «запечённой» яркостью граней. Сверху камера видит в основном верх: важное (стёкла, кабину) делать видимым сверху — наклонными гранями или выше загораживающих частей.
- **Соседи держат персонажей под силу игрока** — редкость его третьего по редкости персонажа (`BOT.powerDepth`, `playerPower` в `neighbors.ts`): одна удача из кейса не поднимает их на ступень выше. Шансы ступени ниже / такой же / выше — `loot` в `NEIGHBORS`.
- **Соседи прокачиваются** с лучшим доходом игрока (`stats.peakIncome`, без печи и ускорителя), не с его прокачкой — так прокачка игрока остаётся преимуществом. Уровни, собака и колокольчик — `RIVALS`, `DOG` в `config.ts`, логика — `rivals.ts`.
- **Объявления** (`Hud.showBanner`) не должны закрывать кнопки: на компьютере — вверху между колонками кнопок, на телефоне стоя — внизу над кнопками действия и веника, лёжа — под рядом кнопок окон (`.hud-banner` в `style.css`). Длинный текст в других языках проверять на 390×844, 360×640 и лёжа.
- **Окна** (прокачка, кейсы, колесо, парилка, герой) собраны в `menus.ts`, окна удержания (награды за вход, альбом, перерождение, «С возвращением!») — в `retention-menus.ts`, окна площадки (магазин, рейтинг) — в `shop-menus.ts`, их DOM — в `ui/`. Кнопку окна, которого нет на площадке (нет покупок или таблицы рекордов), игра прячет. Открыто не больше одного окна; всплывающие сами (доход вне игры, награда за вход) ждут в очереди (`Menus.popup`). Награда выдаётся, когда анимация остановилась, а если окно закрыли или вкладку свернули раньше — сразу (`Menus.settle`).
- **Удержание (v0.6):**
  - доход вне игры — доля `OFFLINE.rate` (10%) обычного дохода с последнего сохранения (`savedAt`), но не больше `OFFLINE.maxShare` (20%) монет игрока — так решил владелец в v0.9 вместо прежних 3 часов; за рекламу ×2 поверх потолка; считается при запуске до первого сохранения. Долю не поднимать без модели: доход к концу сессии самый высокий, и щедрый офлайн заменяет игру;
  - награды за вход — календарь `DAILY` в `daily.ts` на 7 дней по кругу, сутки по UTC (как спины колеса), пропуск дня сбрасывает серию; само всплывает только после обучения;
  - альбом — `collection` в сохранении («id» и «id:gold»), отмечается в `Home` через `GameContext.collect` при любом получении персонажа;
  - перерождение — `REBIRTH` в `config.ts`: сбрасывает монеты, полок, места, прокачку и `peakIncome` (соседи слабеют, их полки пересаживает `Neighborhood.restock`), оставляет альбом, пасхалки, ключи, таймеры, серию наград и героя; доход ×(1 + 0,5 × перерождений) входит в `incomeFactor`, но не в `baseIncome`. После перерождения — полноэкранная реклама (логическая пауза).
- **Площадка (v0.8)** — `engine/platform`: `Platform` в `platform.ts`, Яндекс — `yandex.ts` (тесты с поддельным SDK — `yandex.test.ts`), разработка и демо — `local.ts`.
  - сохранения: `loadData` отдаёт обе копии (облако и localStorage), игра берёт свежую по `savedAt` (`newestSave`); `saveData` пишет локальную сразу, в облако — не чаще раза в 4 с, `flush` дожидается облака;
  - покупки (`data/shop.ts`, `shop.ts`): только фиксированное содержимое; выдать (`grantPurchase`) → сохранить с `flush` → только потом `consume` для расходуемых; постоянные не «используются» и при каждом запуске приходят в `getPurchases`; токены выданных хранятся в `purchases.granted`, чтобы не выдать дважды; при запуске — обработать необработанные (`Game.restorePurchases`);
  - рейтинг: таблица `LEADERBOARD.name`, лучший доход за всё время (`stats.bestIncome`), отправляют только вошедшие (`records.ts`); вход — из окна рейтинга, если в аккаунте прогресса больше — перезагрузка с него (`hasMoreProgress`);
  - GameplayAPI — только при смене состояния (`Game.syncGameplay`): стоп, когда окно, реклама, окно оплаты или входа, пауза площадки, свёрнутая вкладка;
  - методы SDK, менявшиеся между версиями, адаптер понимает в обоих вариантах; документация Яндекса из облака закрыта — сверено с `defold-yagames`, перед модерацией проверить в черновике;
  - без SDK (не загрузился за 10 с) — `LocalPlatform` без покупок, рейтинга и наград за рекламу; демо-покупки, пример рейтинга и кнопка 🌐 — только в демо и при разработке (`isDemoBuild`); бесплатных покупок в сборке для площадки быть не должно;
  - Консоль, архив, тексты карточки и проверка в черновике — по шагам в `docs/yandex-release.md`.
- **Языки (v0.9)** — `games/steal/src/i18n`: словари `ru` (образец, тип `Messages`), `en`, `tr`, `es`, `pt`, `de`, `fr`, выбор языка — `pickLanguage`, текущий словарь — `t`.
  - Все тексты интерфейса и мира — только через `t`; модули данных хранят id, а названия отдают геттерами из словаря (`characterName`, `caseName`, `secretText`).
  - Тексты с числами и именами — функции: порядок слов и падежи у языков свои. Числа передавать уже записанными (`formatNumber`, `formatDecimal`, `formatSeconds`, `formatChance`, `formatPercent`, `formatMultiplier` из `i18n`): знак процента и десятичный разделитель у языков разные.
  - Новый текст — во все словари сразу: TypeScript требует те же ключи, а `i18n.test.ts` проверяет пустые строки, оставшуюся кириллицу, казино-лексику и длину подписей кнопок окон.
  - Фразы о самом игроке — без рода (герой может быть девушкой).
  - Имена соседей в падежах — поля `object` и `holder` в словаре. В турецком к именам персонажей не приклеивать окончания: строить фразу так, чтобы имя стояло отдельно.
  - Язык: на площадке — только из SDK (правила 2.10, 2.14); при разработке и в демо — кнопка 🌐, `?lang=` или язык браузера (`main.ts`, `LANGUAGE_KEY`).
- **«Голда»** — вариант любого персонажа (`gold` в сохранении): доход ×2, цена ×2,5 (`GOLD` в `config.ts`). Золотые спрайты `<id>-gold.png` рисует `goldify` в `tools/art` — вручную их не делать.
- **Случайные механики** — шансы задаются в `data/cases.ts`, `wheel.ts`, `config.ts` (`UPGRADER`) и всегда показываются игроку. Тест держит среднюю ценность кейса между 70% и 85% цены: меняются цены персонажей — пересчитать и цены кейсов.
- **Темп** проверяет модель прохождения `pacing.ts`: два модельных игрока (спокойный и активный) играют по правилам и числам игры, `pacing.test.ts` держит медианы вех (легендарный, мифический, все места, доход, перерождения) в целевых рамках и проверяет, что прокачка поспевает за соседями, а ночной доход вне игры без рекламы меньше цены перерождения. Меняешь цены, доход, места, кейсы, офлайн или перерождение — смотри `npm run pacing` и обнови таблицу в `docs/game-1-steal.md` (раздел «Темп»). Доход персонажей трогать осторожно: от него зависят уровни соседей и цены прокачки.
- **Баланс** — числа в `config.ts` (скорости, сон и щеколды соседей, их уровни, веник, цены прокачки). Сложность краж проверена сценариями: без веника при бодрствующем хозяине кража не удаётся; с ударом первым игрок, прокачанный по доходу, успевает с ближнего к выходу места и не успевает с дальнего.
- **Музыка** пишется нотами в `src/music.ts` и синтезируется `engine/chiptune.ts` прямо в игре (понемногу в каждом кадре) — файлов нет. Голоса фона мягкие: синусоида с плавной атакой и хвостом (`attack`, `release`), лёгкое эхо (`echo`); квадратных «пищащих» голосов в фоне нет (проверяет тест). Трек из ТикТока (`sounds/rare-theme.mp3`) играет при появлении редкого персонажа, плавно появляется и затихает, фон на это время притихает (как и под балалайку медведя). Короткие звуки мира (лай, колокольчик, пар) — синтезированные `blip` в `engine/audio.ts`.
- **Картинки рисуются кодом** в `tools/art`:
  - `characters.mjs` — персонажи 32×32 по 2 кадра и герои 24×24 по 4 направления × 4 кадра ходьбы;
  - `textures.mjs` — тайлы и мелочи;
  - `banya.mjs` — грани печи, камни, трубы, клубы пара, дранка и наличник, веники и шапка, кадка;
  - `scenery.mjs` — лес, пасхалки, звери, постройки;
  - `vehicles.mjs` — грани машин, трактора и порталов. PNG в `games/steal/src/assets` не править руками — поменять генератор и запустить `npm run art`. Превью всех листов — `tools/art/preview.png`. В игре картинки берутся по имени файла (`data/sprites.ts`).
- **Герои** на выбор игрока — `data/heroes.ts` (`hero` в сохранении), окно «Герой» (H или портрет справа вверху). Листы `hero-girl`, `hero-guy` рисуют `heroGirl`, `heroGuy` трафаретами в `tools/art/characters.mjs`; соседи-боты — прежний герой (`neighbor()`) в своих цветах. Герой должен быть взрослым, одетым и без пошлости (требование площадки 8.3.6).
- **Новый персонаж:** нарисовать в `tools/art/characters.mjs` → добавить в `CHARACTERS` в `tools/art/build.mjs` (имя файла = id, «Голда» рисуется сама) → `npm run art` → строка в `games/steal/src/data/characters.ts` (+ звук в `src/sounds`) → имя во все словари `i18n` (`characters`, при желании — фразы в `shelf.own`).
- **Сохранения:**
  - формат — `SaveData` в `save.ts` (сейчас версия 7);
  - `id` персонажей после релиза не менять;
  - при изменении формата поднять `version` и дописать миграцию в `parseSave`.
- **Артефакт (игра по ссылке):** `npm run artifact -- <путь>/steal.html` собирает страницу и рядом `steal.js` (картинки и звуки встроены data:-ссылками, режим `demo`: без Yandex SDK, вместо рекламы, оплаты и входа — табличка на 1,5 с, покупки бесплатные, рейтинг — пример, язык меняется кнопкой 🌐). ## Ограничения площадки — не нарушать

- **Кейсы, колесо удачи, апгрейдер** — только за внутриигровую валюту. За Яны — только наборы с фиксированным содержимым. Шансы выпадения всегда видны. Никакой казино-лексики и визуала: «ставка», «джекпот», рулетка, краш.
- **Покупки** — только через SDK; при запуске проверяются необработанные (`getPurchases`); `consumePurchase` — только после сохранения; цена и значок валюты — из каталога (`getCatalog`).
- **Реклама** — только через Yandex Games SDK (`engine/platform`):
  - полноэкранная — только в логических паузах;
  - за вознаграждение — только по желанию игрока, на кнопке видно, что это реклама и какая награда;
  - награда — бонус: игра продолжается и без неё;
  - во время любой рекламы игра и звук на паузе.
- **Обязательно:**
  - `LoadingAPI.ready()` после загрузки;
  - язык определяется через SDK;
  - прогресс сохраняется сразу после действий игрока, в том числе у гостей;
  - покупки только через SDK, при запуске проверяются необработанные;
  - звук выключается при сворачивании вкладки.
- **Персонажи:**
  - реальные медийные личности — узнаваемые образы с их согласия (подтвердил владелец проекта);
  - бренды — только пародийные (например, «Dodge Cabana»);
  - персонажи чужих франшиз (Астольфо и т. п.) — только свои аналоги.
- **Сборка:** `index.html` в корне архива, до 100 МБ, имена файлов без кириллицы и пробелов, без внешних ссылок и запросов — всё это проверяет `npm run package`.
