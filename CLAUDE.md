# CLAUDE.md

Контекст для Claude Code в этом репозитории.

## Проект

- Серия браузерных игр для Яндекс Игр. Список основ и статусы — в `README.md`. Исследование рынка и правил площадки — `docs/research-2026-09.md`: сверяйся с ним, прежде чем проектировать механику и экономику.
- Пользователь пишет по-русски — отвечай по-русски. Тематику и референсы (внешний вид) задаёт пользователь. Механику, экономику и удержание предлагаешь ты, опираясь на проверенные жанры.
- Текущая игра — №1 «Собери / укради X» в тематике «ТикТок-брейнрот». Кода пока нет, ждём референсы и сводку от пользователя.
- Стек (предварительно): TypeScript + Vite + Three.js. Мир в 3D, персонажи — пиксельные спрайты-билборды.

## Ограничения площадки — не нарушать

- **Кейсы, колесо удачи, апгрейдер** — только за внутриигровую валюту. За Яны — только наборы с фиксированным содержимым. Шансы выпадения всегда видны. Никакой казино-лексики и визуала: «ставка», «джекпот», рулетка, краш.
- **Реклама** — только через Yandex Games SDK:
  - полноэкранная — только в логических паузах;
  - за вознаграждение — только по желанию игрока, на кнопке видно, что это реклама и какая награда;
  - награда — бонус: игра продолжается и без неё;
  - во время любой рекламы игра и звук на паузе.
- **Обязательно:**
  - `LoadingAPI.ready()` после загрузки;
  - язык определяется через SDK;
  - прогресс сохраняется сразу после действий игрока, в том числе у гостей;
  - покупки только через SDK, при запуске проверяются необработанные;
  - звук выключается при сворачивании вкладки.
- **Персонажи** — свои, «в стиле» тренда. Не копировать чужих персонажей и бренды: у CS2 и Standoff 2 — товарные знаки, по брейнрот-персонажам идут суды.
- **Сборка:** `index.html` в корне архива, до 100 МБ, имена файлов без кириллицы и пробелов, без внешних ссылок.
