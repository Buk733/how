# CLAUDE.md

Контекст для Claude Code в этом репозитории.

## Проект

- Серия браузерных игр для Яндекс Игр. Список основ и статусы — в `README.md`. Исследование рынка и правил площадки — `docs/research-2026-09.md`: сверяйся с ним, прежде чем проектировать механику и экономику.
- Пользователь пишет по-русски — отвечай по-русски. Тематику и референсы (внешний вид) задаёт пользователь. Механику, экономику и удержание предлагаешь ты, опираясь на проверенные жанры.
- Текущая игра — №1 «Укради Брейнрота: Баня» (`games/steal`). Дизайн, состав персонажей и этапы — `docs/game-1-steal.md`. Готовы v0.1 (основной цикл) и v0.2 (кражи, соседи-боты, погоня, набеги, щеколда), дальше v0.3 — кейсы, колесо удачи, апгрейдер, «Голда».

## Разработка

- Стек: TypeScript + Vite + Three.js, тесты — Vitest. Мир в 3D, персонажи — пиксельные спрайты-билборды.
- Команды:
  - `npm run dev` — запуск игры;
  - `npm test` — тесты;
  - `npm run build` — проверка типов и сборка;
  - `npm run art` — перегенерировать картинки.
- Перед коммитом: `npm test && npm run build`.
- `engine/` — общий движок для всех игр, импортируется как `@engine/...`. Код конкретной игры в него не тащить.
- Чистая логика — в отдельных модулях с тестами рядом (`*.test.ts`): `economy.ts`, `neighbors.ts`, `save.ts`, `spawner.ts`, модули `engine/`. Графику и DOM держать в `game.ts`, `world.ts`, `carpet.ts`, `home.ts`, `neighborhood.ts`, `entities/`, `ui/`. Общие сервисы для них — `GameContext` (`context.ts`), его реализует `Game`.
- **Картинки рисуются кодом** в `tools/art` (`characters.mjs` — персонажи 32×32 по 2 кадра, `textures.mjs` — тайлы и декор). PNG в `games/steal/src/assets` не править руками — поменять генератор и запустить `npm run art`. Превью всех листов — `tools/art/preview.png`.
- **Новый персонаж:** нарисовать в `tools/art/characters.mjs` → добавить в `tools/art/build.mjs` → `npm run art` → строка в `games/steal/src/data/characters.ts` (+ звук в `src/sounds`).
- **Сохранения:**
  - формат — `SaveData` в `save.ts`;
  - `id` персонажей после релиза не менять;
  - при изменении формата поднять `version` и дописать миграцию в `parseSave`.
- **Проверка в браузере:** Chromium для Playwright уже установлен (`PLAYWRIGHT_BROWSERS_PATH`). В режиме разработки в консоли доступен `window.game` (сохранение, игрок, персонажи).
- Код и идентификаторы — на английском, комментарии и тексты интерфейса — на русском.

## Ограничения площадки — не нарушать

- **Кейсы, колесо удачи, апгрейдер** — только за внутриигровую валюту. За Яны — только наборы с фиксированным содержимым. Шансы выпадения всегда видны. Никакой казино-лексики и визуала: «ставка», «джекпот», рулетка, краш.
- **Реклама** — только через Yandex Games SDK (`engine/platform`):
  - полноэкранная — только в логических паузах;
  - за вознаграждение — только по желанию игрока, на кнопке видно, что это реклама и какая награда;
  - награда — бонус: игра продолжается и без неё;
  - во время любой рекламы игра и звук на паузе.
- **Обязательно:**
  - `LoadingAPI.ready()` после загрузки;
  - язык определяется через SDK;
  - прогресс сохраняется сразу после действий игрока, в том числе у гостей;
  - покупки только через SDK, при запуске проверяются необработанные;
  - звук выключается при сворачивании вкладки.
- **Персонажи:**
  - реальные медийные личности — узнаваемые образы с их согласия (подтвердил владелец проекта);
  - бренды — только пародийные (например, «Dodge Cabana»);
  - персонажи чужих франшиз (Астольфо и т. п.) — только свои аналоги.
- **Сборка:** `index.html` в корне архива, до 100 МБ, имена файлов без кириллицы и пробелов, без внешних ссылок и запросов.
